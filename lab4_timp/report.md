# Отчет: проектирование БД (тема: физическая безопасность)

## Таблица 1 — Определение набора сущностей

| Сущности | Описание сущностей |
|---|---|
| `user` | Содержит данные о пользователях системы: логин, email, хэш пароля, роль |
| `facilities` | Содержит данные об охраняемых объектах: название, адрес, уровень безопасности |
| `incidents` | Содержит данные об инцидентах безопасности: заголовок, описание, статус, критичность, время |
| `checkpoints` | Содержит данные о точках контроля доступа на объекте (входы/КПП/двери) |
| `security_plans` | Содержит данные о планах физической безопасности для объекта |

### Обоснование добавления новых таблиц

- `checkpoints` нужна для фиксации структуры контроля доступа по каждому объекту. Без нее нельзя понять, где именно произошел сбой или нарушение.
- `security_plans` нужна для хранения формализованных мер защиты (процедуры, период действия, ответственные). Это связывает инциденты с действующими планами и позволяет анализировать эффективность.
